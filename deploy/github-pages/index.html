What it actually does

◈

Opaque QR, sealed payload

QR codes carry a random 128-bit token. Visitor details sit encrypted at rest with a per-pass key; the scanner always asks the server.

▤

Walk-ins are first-class

Guests without phones get a printed sticker from a managed pool. Claiming binds it atomically to a new pass — no shared credentials.

⌁

Scoped dashboards

Hosts see their own visitors active, upcoming and ended. Admins see everything. Guards see only what the gate needs.

⛓

Tamper-evident logs

Access and audit events are hash-chained. Editing or deleting a row breaks verification and names the first bad sequence.

◎

Advisory anomaly flags

An IsolationForest sidecar scores scan patterns asynchronously. It never sits on the decision path and never blocks a guard.

⟳

Self-hosted by design

Caddy, Next.js, Go, Postgres and the ML sidecar in five containers. One compose file, one machine, no vendor lock-in.
